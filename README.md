# Apple Ecosystem Visualization

An interactive force-directed graph visualization of the Apple developer ecosystem, showing relationships between key stakeholders.

## Features

- **Force-directed layout** with category-based clustering
- **Interactive nodes** - hover to see relationships, click to view details
- **Responsive design** - adapts to desktop and mobile screens
- **Color-coded connections** by type (data flow, content, user connections, etc.)
- **Weighted relationships** - line thickness indicates relationship strength
- **Bidirectional connections** - parallel lines for two-way relationships
- **Zoom and pan** controls for exploration

## Quick Start

### View Online
Visit: https://simonellistonball.github.io/cjbs-strategy-assignment-4/

### Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Technology Stack

- **React** - UI framework
- **D3.js** - Force-directed graph simulation
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling

## Distribution

The built files in the `dist/` folder are standalone and can be:
- Opened directly in a browser (open `dist/index.html`)
- Hosted on any static web server
- Deployed to GitHub Pages, Netlify, Vercel, etc.
